# Rúbrica del proyecto

Puntúa cada dimensión de 0 a 3: 0 = sin evidencia evaluable; 1 = inicial; 2 = adecuado; 3 = sólido. Nota orientativa sobre 10: `10 × suma(peso × nivel/3)`, usando pesos decimales. La coordinación fija la ponderación en la asignatura.

| Dimensión | Peso | Nivel 1 · Inicial | Nivel 2 · Adecuado | Nivel 3 · Sólido |
|---|---:|---|---|---|
| Problema y datos | 25 % | Problema amplio; origen o separación poco claros | Usuario, decisión, datos y separación identificados | Criterio de éxito previo, unidad independiente y límites de cobertura justificados |
| Método y justificación | 25 % | Ejecuta código sin explicar elección ni referencia | Compara referencia y propuesta con un cambio explícito | Hipótesis clara, comparación coherente y decisiones registradas en validación |
| Evaluación y errores | 30 % | Cifra aislada o errores sin analizar; posible fuga | Métricas pertinentes, prueba separada y dos casos o límites | Protocolo y denominadores explícitos, separación coherente y conclusiones ajustadas a evidencia |
| Claridad y reproducibilidad | 20 % | Entrega incompleta o ejecución difícil de seguir | Notebook ejecutable, informe breve y evidencias vinculadas | Versiones, parámetros, procedencia y resultados coherentes; defensa clara y comprobación futura concreta |

El nivel 0 se aplica por dimensión cuando no se aporta evidencia suficiente para valorar ese criterio. Un resultado bajo del modelo no implica automáticamente nivel bajo: se valora la calidad del procedimiento y su análisis. Una fuga de datos impide considerar sólida la evaluación hasta corregirla o reconocer que se requiere otra prueba.

## Revisión entre equipos

- Una decisión bien respaldada por evidencia.
- Una limitación o afirmación que necesita matizarse.
- Una pregunta sobre datos, separación o evaluación.
- Una comprobación futura concreta.

No se publican nombres ni calificaciones de alumnos en el repositorio.
