# Publicar con GitHub Desktop

1. En GitHub Desktop, elige **File → Add Local Repository**.
2. Selecciona la subcarpeta `vision-ia-producto`, no la carpeta general del curso.
3. Revisa los archivos y crea el primer commit, por ejemplo: `Estructura inicial y primeras prácticas`.
4. Pulsa **Publish repository**. Revisa nombre, descripción y visibilidad. Desmarca **Keep this code private** si quieres acceso público.
5. Copia la URL publicada. Ya puedes compartirla con los alumnos.

El repositorio local se entrega sin commits ni conexión remota. No se publica nada automáticamente.

## Enlaces directos a Colab

Después de publicar, sustituye `USUARIO` y `REPOSITORIO` en esta dirección por los valores reales:

```text
https://colab.research.google.com/github/USUARIO/REPOSITORIO/blob/main/00_preparacion/00_comprobar_entorno.ipynb
```

Para otras prácticas, cambia la ruta final. Comprueba el enlace sin iniciar sesión en GitHub antes de compartirlo. Un repositorio privado necesita un procedimiento de acceso distinto.
